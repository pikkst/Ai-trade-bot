# AI Agents

Agents are bounded typed services, not unrestricted autonomous processes.

- Market Analyst: regime assessment
- Technical Analyst: trend, momentum, volatility, volume
- News Analyst: structured event classification
- Risk Analyst: explains deterministic risk result
- Strategy Reviewer: records agreement or disagreement
- Supervisor: aggregates validated reports
- Auditor: checks lineage and schemas
- Reporting Agent: writes experiment summaries

Every agent defines version, purpose, input schema, output schema, timeout, token budget, retry policy, validation, fallback, and audit requirements.
