# Observability

Structured JSON logs include service, environment, request ID, correlation ID, workspace ID, job ID, entity ID, event, error code, and duration. Secrets and signatures are redacted.

## Metrics
Ingestion lag, missing candles, provider errors, AI latency and schema failures, token cost, intents, approvals, rejections, orders, fills, fees, P&L, drawdown, API latency, queue depth, database pool, CPU, and memory.

## Alerts
Critical: reconciliation mismatch, drawdown halt, database failure, duplicate attempts, credential errors.

Warning: stale data, AI schema failure spike, ingestion lag, queue depth, and cost budget threshold.
