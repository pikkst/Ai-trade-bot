# Technology Stack

## Backend
Python 3.12, FastAPI, Pydantic 2, SQLAlchemy 2, and Alembic.

## Data and Jobs
PostgreSQL, Redis, Celery or ARQ, and Pandas or Polars.

## AI
OpenAI-compatible API, Ollama, vLLM, and JSON Schema validation.

## Frontend
React, TypeScript, Vite, and TanStack Query.

## Infrastructure
Docker Compose, Prometheus, Grafana, and GitHub Actions.

## Quality
Pytest, Hypothesis, Ruff, MyPy, Bandit, Semgrep, and Trivy.

Selections prioritize maintainability, typing, local development, reproducibility, and replaceable provider adapters.
